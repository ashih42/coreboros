# Corewar

This project is a fully ICWS'94-compliant implementation of CoreWar Redcode assembler and MARS virtual machine, written in Rust.

## References

- [Beginner's Guide to Redcode](https://corewars.org/docs/guide.html)

- [pMARS Manual](https://corewar.co.uk/pmars/pmars_man.htm)
  - Wherever they differ, refer to pMARS implementation as the source of truth, instead of the ICWS'94 Standard.

- [ICWS'94 Standard](https://corewar.co.uk/standards/icws94.htm)
  - This document is incomplete, and it is not even officially adopted! (ノಠ益ಠ)ノ彡┻━┻

- [n1LS's Collection of Redcode Warriors](https://github.com/n1LS/redcode-warriors)
